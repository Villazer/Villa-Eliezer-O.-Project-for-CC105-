How to Add a New Model

Train a model with train_model_v1.py or train_model_v2.py, drop the .pkl into models/, then activate it above.

# V1 — fast, descriptor-only
python train_model_v1.py \
  --data Video_games_esrb_rating.csv \
  --out  models/my_v1.pkl --algo gb

# V2 — enriched (requires Kaggle dataset)
python train_model_v2.py \
  --esrb   Video_games_esrb_rating.csv \
  --kaggle Video_Games_Sales_with_Ratings.csv \
  --out    models/my_v2.pkl

The Kaggle dataset can be downloaded from kaggle.com/datasets/rush4ratio/video-game-sales-with-ratings
